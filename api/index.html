Multi-Motors — Données publiques FPV

Base de données communautaire de 13819 moteurs brushless FPV (220 marques), mise à jour quotidiennement (2026-11-16T13:13:29Z).

Téléchargement direct & Endpoints

  • moteurs.csv — Catalogue complet au format CSV (UTF-8)
  • moteurs.json — Catalogue complet au format JSON
  • marques.json — Liste des marques et nombre de modèles
  • stats.json — Statistiques globales et date de mise à jour

Exemple d'appel (JavaScript)

const res = await fetch("https://raw.githubusercontent.com/TakDai/Multi-Motors-Catalogue/main/api/moteurs.json");
const data = await res.json();
console.log(data.count, data.motors[0]);
